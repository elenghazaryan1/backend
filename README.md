# Backend

A collection of backend development projects, exercises, and experiments built while learning server-side programming and backend technologies.

## Overview

This repository contains practical implementations of backend concepts, programming exercises, and small projects developed to improve problem-solving skills and understand how backend systems work.

## Topics Covered

- JavaScript and Node.js
- CommonJS Modules
- Module Systems and Custom `require()`
- File System Operations
- Synchronous and Asynchronous Programming
- Higher-Order Functions
- HTTP and Request-Response Cycle
- Backend Architecture and Fundamentals

## Technologies

- JavaScript
- Node.js
- Git & GitHub

## Repository Structure

Projects and exercises are organized into separate directories, each containing its own source code and related files.

## Getting Started

Clone the repository:

```bash
git clone https://github.com/elenghazaryan1/backend.git
```

Navigate to the project directory:

```bash
cd backend
```

Run a JavaScript file using Node.js:

```bash
node filename.js
```

## Purpose

The purpose of this repository is to document my learning progress, practice backend development concepts, and build a strong foundation in server-side programming.
